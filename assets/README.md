# assets

The pictures on the main README page.

- `simulated_*.png` and `simulated_tracking.gif`: made by `python tools/make_readme_images.py` from simulated videos with known values. Plots made from simulated data say "simulated" in the file name and in the title.
- `app_*.png`: screenshots of the Streamlit app, made by `python tools/app_screenshots.py` (needs Playwright).
- `pipeline.png`: the diagram of the analysis steps.

Pictures from real recordings go here too. Give them names that do not start with "simulated".
